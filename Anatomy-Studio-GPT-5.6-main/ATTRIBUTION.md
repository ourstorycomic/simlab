# Full Attribution and Asset Register

Prepared August 2, 2026. Source and license metadata should be checked again before redistribution.

## Project foundation

This educational adaptation is based on [`thebuggeddev/anatomy`](https://github.com/thebuggeddev/anatomy), an interactive Three.js anatomy explorer by **thebuggeddev**. The upstream repository describes itself as built with GPT-5.6 Sol. No explicit project license was visible in the upstream repository when this register was prepared; see [LICENSE.md](LICENSE.md).

The educational comparison, curated-reference, student-reflection, exemplar, report-export, responsive-layout, and disclosure layers were developed with OpenAI Codex assistance under human direction.

## Software and fonts

Major runtime dependencies include React, Next.js, Three.js, GSAP, Lucide React, and Tailwind CSS. Each dependency retains the license published with its package. Exact versions appear in `package.json` and `package-lock.json`.

The application loads DM Sans and Cormorant Garamond through `next/font/google`; each font is distributed under its own upstream license and is bundled into the exported site at build time.

## Attribution maintenance

When replacing or adding a reference image:

1. verify that the file depicts the intended anatomy;
2. save the original source record, creator, title, and exact license;
3. update both the interface metadata in `app/components/AnatomyApp.tsx` and this register;
4. preserve ShareAlike obligations where applicable; and
5. do not describe an AI illustration or generic diagram as real anatomical evidence.
